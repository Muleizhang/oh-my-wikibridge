# 检索、RAG 与评价方案

## 1. 测试问题集

针对每个主题语料库建立人工问题集。纹样语料覆盖三册资料，其他语料库使用与主题相关的问题模板。问题集至少包含以下类型：

- 事实查询：某纹样属于哪个时期
- 属性查询：某纹样使用什么材质或技法
- 关系查询：某类纹样装饰在哪些器物上
- 比较查询：两个时期的纹样有什么差异
- 演变查询：某个母题如何从早期发展到晚期
- 图像查询：寻找与给定纹样相似的图版
- 证据查询：哪些页面支持某个结论

每个问题记录标准答案、相关实体、证据页面和允许的答案范围。

跨语料库测试还记录语料库范围，验证检索结果不会把不同主题或不同用户语料库的内容混在一起。

## 2. 检索对照

至少比较以下方法：

1. 关键词检索
2. TF-IDF 检索
3. Word2Vec 相似度检索
4. 文本向量检索
5. 图谱查询
6. 混合检索

评价指标包括 Recall@k、MRR、nDCG，以及人工判断的相关性和证据完整性。每种格式至少保留一组测试问题，用于检查页码、幻灯片、表格单元格、段落和时间点等定位信息是否正确。

## 3. RAG 评价

对每个回答评价以下项目：

- 是否回答了问题
- 是否使用了正确的时期、地域、材质和器物信息
- 引用页面是否真的支持回答
- 是否包含检索结果之外的无依据内容
- 是否能展示相关纹样图像和关系路径
- 面对资料不足时是否保留不确定性

可以使用五级人工评分，并单独记录引用正确率。

## 4. 图谱评价

从三册中抽取人工标注样本，评估：

- 实体识别 Precision、Recall、F1
- 关系识别 Precision、Recall、F1
- 页面和图像关联正确率
- 时间、地域和材质属性的填充率
- 关系查询结果的人工准确率

## 5. 可复现要求

- 固定文档版本和页面标识
- 固定 OCR 配置和清洗规则
- 保存抽取后的结构化数据
- 保存问题集和检索参数
- 为 RAG 回答保留工具调用记录
- 页面引用可以回到原始页面图像

## 6. 预期展示

最终演示按照一个问题完成完整链路：

```text
输入问题
  -> 检索页面和结构化实体
  -> 查询关系图谱
  -> 找到相似纹样图像
  -> 生成带页码引用的回答
  -> 展示关系图、时间轴和证据卡片
```
