# 评价方案

| 对象 | 样本与指标 |
| --- | --- |
| 检索 | 固定问题与相关页，比较关键词、TF-IDF、向量、图谱与混合检索的 Recall@k、MRR 和 nDCG |
| 抽取 | 按卷和页型独立标注实体、关系、修饰字段、身份与图片绑定，报告 Precision、Recall 和 F1 |
| 问答 | 核对问题覆盖、事实、引用页和不确定性，分开记录引用正确率 |
| 复现 | 固定 PDF 哈希、页码、模型版本、配置、查询与工具轨迹 |

问题集覆盖事实、属性、关系、对比、路径、图片与出处。结构校验检查来源区间、引用和数据库外键。历史机器候选数量及字段覆盖可用于回归对照，语义准确率由独立样本估计。[复现检查](reliable-pipeline.md#检查)
