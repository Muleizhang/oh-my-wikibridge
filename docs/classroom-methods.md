# 课堂方法结合方案

项目优先复用与知识抽取、文本表示、知识图谱、检索和智能体相关的课堂方法。每种方法都对应一个可以验证的系统模块。

## 1. 方法映射

| 课堂作业 | 项目中的使用方式 | 产出 |
| --- | --- | --- |
| HW1 知识表示 | 将 OCR 文本和图注整理为实体—关系—实体三元组 | 三元组样例和问答模板 |
| HW2 Word2Vec | 建立纹样、题材、器物和材质的词语相似度 | 相似词查询和语义检索基线 |
| HW3 知识图谱 | 使用 RDF、SPARQL 和 GraphML 表达与查询纹样关系 | 知识图谱、查询结果和关系图 |
| HW5 NER | 识别时代、地域、器物、材质、题材等实体 | 实体抽取模块和人工校验集 |
| HW6 工具调用智能体 | 让 RAG 智能体调用全文检索、图谱查询和图像检索工具 | 多工具问答流程 |
| HW7 BoW 与 TF-IDF | 构建关键词检索基线并与语义检索比较 | 词法检索指标 |
| HW7 共现矩阵 | 分析纹样术语、器物和材质之间的共现关系 | 共现矩阵和网络图 |
| HW7 SVD | 对共现矩阵或文本向量降维，观察类别和时期分布 | 二维投影和聚类可视化 |

## 2. HW1 的知识表示

从简单三元组开始建立可检查的知识单元：

```text
(凤鸟纹, 出现于, 战国)
(凤鸟纹, 装饰于, 青铜器)
(凤鸟纹, 使用材质, 漆器)
(几何纹, 具有构成方式, 连续)
(某页面, 记载, 凤鸟纹)
```

每个三元组附加来源页面、证据文本、抽取方式和置信度。

## 3. HW2 与 HW7 的检索基线

项目保留简单方法作为可解释基线：

1. BoW 统计词项出现情况。
2. TF-IDF 提高稀有术语的检索权重。
3. Word2Vec 查询与纹样相关的题材、器物和材质词。
4. 现代文本向量模型提供句子级语义检索。

对同一组测试问题比较各方法的 Recall@k、MRR 和人工相关性。这样可以说明 RAG 的回答质量来自检索模块和知识库，而不是只展示生成模型的输出。

## 4. HW3 的 RDF 图谱

图谱可以使用 RDF 三元组表达实体关系，使用 SPARQL 查询：

```sparql
SELECT ?pattern ?material ?period
WHERE {
  ?pattern :usesMaterial ?material .
  ?pattern :belongsToPeriod ?period .
  FILTER (?period = :WarringStates)
}
```

图谱中保留来源和证据关系，使每个查询结果可以跳转到对应页面。

## 5. HW5 的实体抽取

NER 模块负责识别 OCR 文本中的实体类型：

```text
PERIOD      战国、秦、汉、唐
REGION      楚地、中原、关中
MOTIF       凤鸟、龙、虎、云气
ARTIFACT    青铜器、漆器、织物、玉器
MATERIAL    铜、漆、玉、丝织物
TECHNIQUE   錾刻、彩绘、织绣
```

第一版可以采用词典、规则和人工修订结合的方式建立训练数据，再比较 BiLSTM 或 CRF 序列标注方法。模型输出必须经过来源页面核验。

## 6. HW6 的工具调用智能体

RAG 智能体提供以下工具：

```text
search_pages(query, filters)
query_graph(sparql_or_template)
find_similar_text(query, top_k)
find_similar_images(image_or_pattern_id, top_k)
get_evidence(entity_id)
```

工具调用过程保留在会话记录中。回答阶段把工具结果整理为带来源的自然语言说明、关系路径和图像卡片。

## 7. HW7 的关系分析

使用共现矩阵统计以下词语之间的关系：

- 纹样母题与时代
- 纹样母题与器物
- 材质与装饰技法
- 地域与风格术语

使用 SVD 或 PCA 将词语、页面或纹样向量投影到二维空间，用于观察时期、材质和题材的聚集情况。

## 8. 方法组合后的完整链路

```text
OCR 页面
  -> NER 和规则抽取
  -> HW1 三元组表示
  -> HW3 RDF 图谱
  -> HW2 / HW7 检索基线
  -> 图谱查询和向量检索
  -> HW6 工具调用 RAG
  -> 图谱、时间轴、相似图像和证据卡片
```
