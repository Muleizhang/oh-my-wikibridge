# 总体设计

## 1. 项目定位

项目暂定名称为“可扩展多模态知识工程与 RAG 可视化系统”。中国古代纹样是第一组示例语料，系统的知识模型和处理流程不绑定于纹样主题。

系统将用户添加的多种资料处理为有来源、有结构、有媒体关联的知识库。对于纹样语料，系统可以围绕历史演变、题材分类、装饰对象、材质、工艺和地域风格开展查询与分析。对于其他主题，系统复用相同的文档、实体、关系、证据和检索接口。

项目的主线是：

```text
多格式资料
  -> 格式识别与内容提取
  -> 页面、幻灯片、表格、段落和媒体单元整理
  -> 文档分块和媒体区域关联
  -> 实体、属性、关系和证据结构化
  -> RDF 知识图谱与向量索引
  -> 混合检索与 RAG 问答
  -> 关系分析、统计分析和图像可视化
```

网页、图谱、图像画廊和其他交互展示属于知识分析结果的呈现层。核心成果是知识表示、跨格式检索、关系分析和可追溯问答。

## 2. 数据范围与语料库

系统使用“初始语料库 + 用户语料库”的模式。初始语料库是三册《中国纹样全集》，用户可以创建多个主题语料库并继续添加文件。

| 卷册 | 历史范围 | 主要内容 |
| --- | --- | --- |
| 第一册 | 新石器时代、商、西周、春秋 | 纹样起源、早期器物纹样、构成与风格 |
| 第二册 | 战国、秦、汉 | 青铜器、漆器、玉器、陶器、织绣等纹样 |
| 第三册 | 魏晋南北朝、隋、唐、五代 | 雕刻、敦煌、织绣、陶瓷、金银器和绘画等纹样 |

第一阶段对三册全部页面建立页面级 OCR 索引和来源元数据，同时为其他格式建立对应的内容单元索引。第二阶段从全文中识别纹样条目、图注、时代、器物、材质和题材，或根据用户选择的主题抽取其他实体。第三阶段为重点图版、幻灯片、表格和媒体建立内容区域与知识实体的对应关系。

这种分层处理使新资料可以先进入可检索状态，再逐步提高关系图谱和多模态检索的精度。

## 3. 系统模块

### 3.1 文档摄取

- 识别文件格式、MIME 类型、编码和压缩包结构
- 使用格式适配器提取正文、表格、页面、幻灯片、工作表、图像和媒体时间点
- 对扫描页面和图片进行 OCR，对音频和视频按需进行语音识别或关键帧提取
- 识别章节标题、正文、图注、目录、表格标题和参考文献
- 保存原始提取结果、清洗文本和人工修订文本
- 记录适合当前格式的定位信息，保证回答可以返回页码、幻灯片、工作表、单元格、段落或时间点

### 3.2 知识抽取

从 OCR 文本和图注中抽取以下信息：

- 纹样名称和别名
- 时代和历史时期
- 地域、遗址和出土地
- 器物类型和装饰对象
- 材质与工艺
- 题材和母题
- 构成形式、对称方式和连续方式
- 色彩与使用场景
- 与其他纹样的相似、继承或变体关系

抽取结果保留证据句、来源页面和置信度。自动抽取结果进入待校验队列，人工确认后进入高可信知识集。

### 3.3 知识图谱

使用实体、属性和关系表达纹样知识，并保留来源信息。图谱支持 SPARQL 查询、关系路径分析、时间分布统计和 GraphML 导出。

### 3.4 多路检索

系统同时提供：

- BoW 和 TF-IDF 关键词检索
- Word2Vec 词语相似度检索
- 文档语义向量检索
- RDF 图谱查询
- 图像向量相似检索
- 时代、地域、材质和器物等元数据过滤

RAG 使用这些检索结果组成带证据的上下文，不直接依赖生成模型记忆。

### 3.5 RAG 智能体

智能体根据问题选择检索工具，并将检索到的页面、实体、关系和图像结果组织成回答。默认 LLM 后端使用用户本机已经配置的 OpenCode，具体集成方案见 [OpenCode 后端集成](opencode-backend.md)。回答需要展示：

- 结论文本
- 引用的卷册和页码
- 相关图像缩略图
- 使用到的实体关系
- 无法确定或仍需考证的部分

### 3.6 可视化

系统提供以下视图：

- 纹样关系图谱
- 历史时期时间轴
- 题材、材质和器物的统计图
- 纹样图像相似检索结果
- 页面、幻灯片、表格和媒体证据卡片
- RAG 检索路径和引用结果
- 纹样演变或关联关系的路径图

## 4. 计划形成的研究结论

项目围绕三册资料回答以下问题：

1. 不同历史时期的纹样题材分布如何变化。
2. 动物、植物、人物和几何母题与器物类型、材质和工艺之间有什么关系。
3. 同一纹样母题在不同历史时期和地域中如何变体和延续。
4. 构成形式、对称方式和连续方式是否表现出时代或用途差异。
5. 哪些关系可以由书中直接证据支持，哪些关系属于基于图像或文本的分析推断。

结论通过统计图、关系图、时间轴和带页码引用的 RAG 回答共同呈现。

## 5. 分阶段交付

### 阶段一：可检索语料库

- 三册页面清单
- OCR 文本
- 目录和章节元数据
- 页面级关键词检索
- 基础 RAG 问答和页码引用

### 阶段二：结构化知识库

- 纹样实体和属性表
- 关系表和证据表
- RDF 图谱
- SPARQL 查询
- 时代、材质、器物和题材统计

### 阶段三：多模态检索和可视化

- 图版区域裁剪
- 纹样图像嵌入
- 文本与图像联合检索
- 关系图、时间轴和相似纹样画廊
- RAG 引用与可视化联动

### 阶段四：实验报告和展示

- 方法对照实验
- 检索和问答评价
- 关系分析结论
- 演示网页或交互式应用
- 可复现说明和数据字典
