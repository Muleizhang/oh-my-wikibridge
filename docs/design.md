# 总体设计

WikiBridge 把不同格式的资料转换为带出处的内容单元，再提取实体、陈述和可定位的证据。共用的资料模型支持用户语料库和三册《中国纹样全集》。

| 卷册 | 范围 |
| --- | --- |
| 第一册 | 新石器时代至春秋 |
| 第二册 | 战国、秦、汉 |
| 第三册 | 魏晋南北朝、隋、唐、五代 |

桌面工作台中的管理员管理语料、处理草稿和发布版本。读者浏览和检索已发布资料。星图独立展示三册的机器候选，便于按时代、器物、材质和纹样追查来源。

研究问题包括题材分布、载体和工艺差异、地域变体与使用语境。关联路径可以提出历史假说。解释需要回到书页与图注核对。[技术架构](technical-architecture.md) · [知识模型](data-model.md)
