# 用户流程

| 角色 | 流程 | 验收 |
| --- | --- | --- |
| 读者 | 选择语料库，检索文字或关系，打开证据 | 可定位到原文、卷页与相关图片 |
| 读者 | 在星图查找器物或纹样，切换时代、材质等维度 | 长河、图录、2D/3D 星图和原页指向同一记录 |
| 读者 | 发起路径、对比或 AI 问答 | 能查看选用的图谱工具、引用和计算结果 |
| 管理员 | 创建语料库、导入、运行 OCR 或原生提取 | 版本与处理进度可追踪，异常可复核 |
| 管理员 | 查看候选和来源，发布版本 | 读者可检索已发布内容 |

优先交付资料导入、检索、图谱、引用和审核。图像相似检索、跨语料库比较与更多格式作为后续扩展。
