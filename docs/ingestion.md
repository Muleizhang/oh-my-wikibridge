# 资料摄取

工作台按格式提取正文、页图、段落、幻灯片和表格等内容单元，保留原始文件、SHA-256、来源定位和抽取方式。桌面端支持常用 Office、结构化文本、PDF 与图片等格式。音视频转写和通用压缩包递归处理属于扩展方向。

管理员选择语料库并导入。系统按内容哈希复用已有资料。扫描 PDF 或图片可逐批 OCR，已保存页面支持继续处理。提取完成后形成草稿，核对异常和来源后发布。

三册离线流水线保留 Tesseract 与 PP-Structure 两套 OCR 文本及其坐标。机器候选通过文本区间和页图回到原始证据。格式支持与实现入口见 [Rust 适配器](../src-tauri/src/ingest.rs) 和 [浏览器导入](../src/importer.ts)。
