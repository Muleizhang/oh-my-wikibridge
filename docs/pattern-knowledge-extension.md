# 纹样知识维度

当前图谱保存器类、工艺、装饰材料、造型、构图、装饰部位、文化归属和地点等属性。象征意义、信仰与礼仪保留为带语境和出处的文献解释。在图录中可分别查阅器物与文献记载。

后续可补充题材变体、叙事、用途、铭文、颜色与保存状况。制作地、出土地与收藏地分别记录。读图时结合扫描质量、缺损和上下文判断。

原书线索示例。第一册 PDF 第 49 页讨论凤纹的祥瑞语境和商周纹样部位，第 52 页讨论云雷纹构图及其主纹、地纹用法。单件器物的解释应回查图注。
