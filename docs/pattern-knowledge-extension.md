# 纹样知识维度扩展调研

调研日期 2026-11-26。范围为三册《中国纹样全集》、当前图谱数据与公开的艺术品知识组织模型。本文件提出设计建议，不改动抽取结果或现有图谱。

## 当前情况

界面与主要推理集中于年代、文饰和材质，但底层并非只有这三类信息。当前三册 `graph.json` 中还有工艺、尺寸与出土等事件候选。`uses_technique` 共 149 条，分别为 19、86、44 条；这些是未经独立评估的抽取候选数。

项目原有 `docs/data-model.md` 已列出题材母题、地域、工艺、构图和颜色，实际抽取、导出与界面还没有完整实现这些维度。下一步应同时扩展知识表示、抽取和查询，避免只增加展示标签。

器类已作为与时代、纹样、材质同等可访问的独立维度，接入详情、图录、实体搜索与切换、2D/3D 聚类、长河筛选和集合对比。具体器物仍分别记录，共享同名器类概念。

器类概念（如镜）由多件器物实例共享。器物实例分别关联器类、材质、纹饰、工艺与时代；象征意义以有语境与出处的解释记录参与查询。各维度的入口地位可以一致，解释记录仍保留其适用范围。名称同时含多个维度时分别表示，例如铜镜的器类为镜、材质为铜，彩陶盆的器类为盆；资料仅称铜器时，不据此补猜具体器形。

## 可借鉴的知识组织方式

- [Getty AAT](https://www.getty.edu/research/tools/vocabularies/aat/about.html) 将相关概念、物理特征、风格与时期、活动、材料及对象等分开组织。可以借鉴其分面设计，整理工艺、器形和构图术语。AAT 本身不收录所有图像学题材，不能用它包办纹样意义。
- [Getty CONA 的对象与题材模型](https://www.getty.edu/research/tools/vocabularies/cona/about.html) 区分题材描述、识别与解释，还记录题材位于对象的哪个部分。适合借鉴“看见的图案元素”和“被赋予的含义”分开建模的方式。这里只借鉴字段设计，不把项目运行依赖于该服务。
- [CIDOC CRM E13 Attribute Assignment](https://cidoc-crm.org/html/cidoc_crm_v7.1.3.html#E13) 支持记录某人作出的属性或关系判断，以及判断如何产生；可以并存不同甚至矛盾的判断。适合为象征意义、断代和传播观点保留来源及提出者。
- [CIDOC CRM P65](https://cidoc-crm.org/html/cidoc_crm_v7.1.3.html#P65) 区分实体载体与其承载的视觉内容，可用于理解器物、纹饰实例与纹样概念的不同角色。下文是项目自己的简化设计，不声称已完成 CRM 兼容映射。
- [Iconclass 分类纲要](https://iconclass.org/help/outline) 覆盖自然、社会、宗教、抽象观念和叙事题材，可借鉴层次化题材组织方式。中国古代纹样仍需本地概念体系，不能直接照搬其宗教和神话类别。

## 建议扩展的概念与属性

| 维度 | 具体记录什么 | 示例 | 能支持的研究或查询 |
| --- | --- | --- | --- |
| 工艺 | 成型工艺、装饰工艺及其区别 | 铸造、刻划、模印、镶嵌、鎏金、织锦 | 同一纹样如何随材料与工艺改变 |
| 器类与功能 | 器形、部件、日常或仪式用途 | 盆、壶、铜镜、瓦当；建筑装饰、随葬 | 相同纹样在什么载体与用途下出现 |
| 题材母题 | 纹样描绘或包含的动物、植物、人物、几何单元 | 鸟、鱼、莲花、联珠；对鸟与联珠组合 | 不同名称的纹样是否使用相同母题 |
| 叙事情境 | 多元素共同表现的活动或故事 | 狩猎、乐舞、车马出行 | 区分“有一只鸟”和有明确内容的场景 |
| 构图与形式 | 重复组织、对称、排列、朝向及形态 | 二方连续、四方连续、对称、散点、侧面形、抽象化 | 比较同名纹样的视觉变化 |
| 装饰部位与角色 | 图案在哪个部位，承担主纹、地纹或边饰等何种作用 | 腹部、口沿、肩部；主纹、地纹、边饰 | 云雷纹何时作为主纹，何时衬地 |
| 地域与文化归属 | 发现地、制作地、使用地、现藏地及文化归属分别记录 | 庙底沟、马家窑、良渚、楚文化 | 研究跨地域分布，避免出土地等于产地 |
| 象征意义 | 某纹样在特定语境下被解释为何种观念 | 祥瑞、辟邪、祈愿等有出处的解释 | 按含义检索不同纹样，比较同纹异义 |
| 信仰与礼仪语境 | 宗教、祭祀、丧葬、日常使用等背景 | 佛教造像、随葬玉器、墓葬装饰 | 将纹样解释与实际使用环境联系起来 |
| 变体与传播 | 形态变体、文献提出的承袭或影响关系及适用时期 | 联珠团花与萨珊风格、具象到几何化 | 建立有出处的演变或影响路径 |
| 铭文与文字 | 铭文内容、位置、文字类型、题记中的人物或机构 | 镜铭、题记、文字装饰 | 联合检索文字内容和纹样 |
| 颜色与保存状况 | 资料明确描述的原色、残片状态、修复或缺失 | 红黑彩绘、残片、缺口 | 解释视觉差异，控制相似度比较条件 |

颜色不能从黑白印刷图直接认定；断片上的不完整图案也不宜直接判成非对称。尺寸继续采用带单位的属性值，视觉相似度采用带计算方法的指标，不把每个数值变成实体。

## 概念不能混为同一种属性

| 内容 | 在图谱中的角色 | 关系示例 |
| --- | --- | --- |
| 莲花、兽面、飞天 | 图像题材或被识别的形象 | 纹饰实例描绘某种题材 |
| 佛教、某文化传统 | 解释和使用的文化背景 | 文献解释适用于该背景 |
| 祭祀、供养、随葬 | 使用或仪式活动 | 器物参与活动，或图像描绘活动 |
| 祥瑞、净土、纯洁、辟邪 | 文献赋予的意义或作用 | 解释记录将纹样与意义联系起来 |
| 腹部、背光、边饰、主纹 | 装饰位置与视觉角色 | 某处纹饰位于某部位、承担某角色 |
| 镂空、刻划、织锦 | 制作或装饰方法 | 某器物或纹饰采用某工艺 |

尤其要区分“图像描绘供养活动”和“这件器物曾被用于供养”，二者不能互相推出。

象征意义的检索可先按护佑与辟邪、吉庆与丰收、神圣与宗教观念、身份与权力、自然与宇宙观等方向组织。这些是便于检索的初步上位概念，不是识别结果的封闭词表；具体含义先从语料产生候选，出现新概念时可以补入。

对三册原始 OCR 做了一次不依赖 LLM 的触发句清点，去除同类触发词在同一句中的重复命中后，得到含义相关线索 48 条、信仰礼仪相关线索 66 条、传承交流相关线索 151 条。它们只是召回的原始语句，其中包括泛论、主语不完整、跨时期内容和非纹样层面的讨论，不能当作三元组数量或准确率。完整定位信息保存在忽略目录 `data/local-kg/semantic-research/corpus-clues.json`，尚未入库。

## 象征意义如何表示

采用三个不同层次：

1. 纹样概念，例如凤鸟纹、云雷纹，可用于名称归一与类目检索。
2. 纹饰实例，即某件器物某个部位的一处图案；构图、方向、部位和角色主要挂在这一层。
3. 解释记录，记录某来源如何解释一个实例，或如何解释某时期、文化和用途范围内的一类纹样。

解释记录保留对象、短含义标签、出处和原文。时期、文化与用途可通过原文回看，资料没有提供的内容不补造。按用户要求，不单独存储或展示“可能”等限定字段。

例如，第一册 PDF 98 的材料可生成一条候选解释：

```text
解释对象  良渚随葬玉器上的兽面纹
解释内容  辟邪
语境      良渚文化、玉器、随葬
来源      第一册 PDF 98 的相应段落及引用标记
状态      文献解释候选
```

不能由此推出全部兽面纹都有辟邪意义。同一个纹样概念可以对应多条解释，查询时按语境筛选；通用概念的名称合并不等于将其所有意义合并成无条件事实。

## 抽取与实施顺序

### 自动新增的选择

对当前三册资料，第一批选择自动补入候选图谱的内容如下。来源明确是指关系主体、内容与引用范围明确，不表示已经获得独立人工准确率评估。

| 内容 | 自动新增形式 | 采用条件 |
| --- | --- | --- |
| 器类与器形 | 器物归入盆、壶、镜、瓦当等类型 | 从器物名称或图注明示的载体识别，不从被描绘的物体取器类 |
| 制作与装饰工艺 | 器物或纹饰采用某工艺 | 文本明确写出，绑定到具体图录；优先复用现有 149 条候选 |
| 出土、发现与收藏 | 器物参与事件，地点与收藏者为不同角色 | 图注明确；多地点不拆成每件物体在所有地点都出土，出土地不改成产地 |
| 文化归属 | 器物或有范围的纹样类归属于某文化 | 原文明示，不单凭现代出土地或年代推定 |
| 构图与形式 | 某纹饰实例采用连续、对称等组织形式 | 文本明确且有唯一对象；概括性描述保存为有范围的类级论述 |
| 装饰位置与角色 | 某处纹饰位于腹部、口沿等，承担主纹、地纹等角色 | 同时保存器物、纹饰、部位的绑定；不向所有同名纹样传播 |
| 题材、母题与场景 | 纹饰描绘或包含某元素、活动 | 名称/说明能明确识别；复杂神兽与人物身份不凭单个字拆解 |
| 原文明示的用途、颜色和残缺信息 | 器物或纹饰的属性及使用背景 | 采用文字证据；黑白图不提供原色依据，绘有祭祀图像不等于曾被用于祭祀 |

象征意义、信仰联系、变体与传播观点也可自动新增，但新增的是有出处的文献解释/论述记录。展示“纹样 → 含义”短标签，保留原文供核读；不要求先将观点裁定为历史事实才允许检索和展示。复述或引述的观点不自动改写为编著者本人结论。

暂不自动生成：仅凭图像推断宗教或用途、根据相似度建立历史传承、把某部位构图判定推广到完整残损图案、从黑白印刷图恢复原色、将复杂合成纹样或古文字进行确定性识别、将缺少唯一主语的正文关系分摊给同页全部器物。

实际采用顺序为器类、工艺、地点与文化、构图、部位角色和题材；同时补充少量主语与语境明确的象征意义解释。无需为新增这些数据调用 LLM，也不必重跑已完成的图片标注。

先补工艺、器类、地域文化、构图、装饰部位与角色。这些内容在图注和正文中较具体，能直接改善筛选、对比和视觉检索。底层已有的工艺与出土事件应先接入展示，避免重复抽取。

正文的象征意义和信仰语境已采用 UIE 模型抽取，并用对象专属提示复核配对。结果记录在文献解释层，不能将正文观点直接传播给同页所有器物。用途、演变与影响观点后续再扩展。

新增简单维度采用本地 UIE 与 GLiNER 的模型抽取。按单件图录输入原始 OCR，保存模型给出的字符跨度、分数、模型名与权重版本。规则仅用于来源边界、字段类型、否定和名称规范化；模型没有识别出的值不通过词表补入。通用模型对名称式领域词有漏抽，不能把模型执行成功当作覆盖充分。此前的规则补充草案与首轮结果已回退并归档，不作为当前新增数据。后续可用独立校对样本微调专用模型，并单独评估；规则或模型输出不能充当独立测试真值。象征意义、转述与传播判断仍需要另行处理主语、语境和确定性。

界面可在器物详情卡展示属性，在纹样概念卡展示母题、构图分布与带出处的解释，在推理页支持按语境过滤的比较。尺寸、置信分数等字面量不必在星图中展开为节点。

建议优先支持三个能验证实际价值的问题：

- 哪些纹样在具体文献语境下被解释为辟邪，它们出现在何种器物与用途上？
- 云雷纹在不同时期、载体和部位上，何时作主纹、何时作地纹？
- 联珠纹与哪些母题组合，哪些来源讨论了其与萨珊风格的关联？
