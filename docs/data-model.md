# 知识模型

资料按语料库、来源文件、内容单元、文本块与媒体组织。PDF 的册内 PDF 页码、印刷页和跨册展示页码各自有明确用途。

| 数据 | 含义 |
| --- | --- |
| `graph.json` 的 `records`、`entities`、`assertions` | 源图录、实体和带证据的陈述 |
| `events`、带单位的值 | 出土等事件与尺寸等结构化属性 |
| `interpretations` | 纹样的象征、信仰、礼仪，以及工艺、构图的文献解释 |
| `sourceItems`、`sourceRows` | 展示清单中可追溯的源图录和陈述 |
| `items`、`rows` | 规范器物与生效的展示关系 |

证据保存卷页、OCR 文本区间、坐标、提取方式和审核状态。不同出处的器物通过 `sourceRecordId` 和 `canonicalArtifactId` 关联。名称、出土地与明确测量值的完整匹配可以支持自动合并候选。尚未解决的记录保留待核状态。

材质、造型、工艺、装饰部位和文化归属各自保留出处。文献对纹样的解释留在它适用的语境中。桌面工作台使用草稿和发布状态控制读者可见范围。[星图数据与图片](atlas-frontend-adaptation.md)
