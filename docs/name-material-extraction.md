# 名称材质补充

使用本地图录名称中的明确“材质词＋器物主体”结构补充 `made_of`。原有材质判断保留，只补没有材质绑定的源器物。

这次漏标来自旧材质规则的器物词表缺少“鉴”“匝”等词。补充器物头词后，材质词可以和具体器物绑定。原文“匝”保留，不静默改写成“匜”。

| 名称 | 补充结果 | 证据 |
|---|---|---|
| 战国铜鉴 水陆攻战纹 | 铜 | 原名称中的“铜”“铜鉴”及其原页位置 |
| 战国刻纹铜匝残片 人物鸟兽纹 | 铜 | 原名称中的“铜”“铜匝”及其原页位置 |
| 鹳鸟衔鱼石斧纹彩陶缸 | 陶 | 主体为彩陶缸，石斧属于纹样题材 |
| 鎏金铜鉴 | 铜 | 主体为铜鉴，鎏金为表面工艺 |
| 西汉铜贮贝器 | 铜 | 贮贝器是器物名称，贝为所贮内容 |

规则版本 `catalog-name-material-v1`。依据词形结构，不调用 OCR、嵌入模型或外部大模型。字符空白可规范用于匹配，证据跨度始终回指原 OCR 文本。只写原文支持的材质粒度；“铜”不自动改为“青铜”。

鎏/镀/错/嵌等表面处理、纹样内描绘的对象、仿制语境以及不能判清主体的复合材料名称予以排除或保留核验。名称识别输出仍为 `candidate/unreviewed`，不提升人工审核状态。

本次三册分别新增 81、108、311 条材质候选，共 500 条。当前星图增加 494 条材质来源关系；其余 6 条属于原本未在星图展示的图录，候选保存在原图谱。星图源图录、图片和器物身份映射均保持，规范器物仍为 4063 个，源图录 4075 条。三册 JSON、SQLite、单册及合册展示已更新。

实现位置：

- `scripts/kg_v2/name_materials.py` 为名称解析和补充逻辑。
- `scripts/kg_v2/caption_fields.py` 在后续图注处理时复用此规则。
- `scripts/enrich_name_materials.py` 从现有缓存补充，先更新来源层，再按既有规范器物身份投影。
- `data/local-kg/report/name-material-enrichment.json` 包含版本、每册新增陈述 ID、跳过原因、展示数量及应用前备份位置。

执行方式：

```bash
python3 scripts/enrich_name_materials.py
python3 scripts/enrich_name_materials.py --apply
```

重复执行新增数为 0，不覆盖原材质、器物合并或裁图。应用前对图谱、展示及 SQLite 使用现有备份流程。已验证反例、两个真实记录、源数据和图片保留、幂等性及外键完整性。
